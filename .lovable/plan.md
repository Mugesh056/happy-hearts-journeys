# Happy Hearts Holidays — Official Brand Palette

## Goal
Update the existing landing page’s centralized color system to match the official logo while preserving all content, imagery, layouts, interactions, enquiry behavior, and animations.

## Visual Update
- Set brand blue `#003E87` as the primary color for headings, buttons, icons, navigation states, route graphics, and the footer.
- Set brand yellow `#FED500` as the accent for highlights, active details, focus states, stars, and button hover states.
- Use white `#FFFFFF` for page/card surfaces and light text on blue or image overlays.
- Use dark text `#2B2B2B`, gray text `#666666`, and light background `#F3F4F6` throughout supporting content and alternating sections.
- Remove the previous orange, gold, green, cream, midnight, and unrelated accent treatments by remapping existing semantic tokens.

## Component Styling
- Make primary actions blue with white text and yellow hover with blue text.
- Align secondary, outline, WhatsApp, mobile menu, form, testimonial, card, icon, and footer states with the same blue/white/yellow system.
- Keep dark image overlays only where required for readable white text, using brand blue rather than a separate navy.
- Preserve accessible destructive/error styling as the only functional exception to the brand palette.

## Verification
- Check desktop, tablet, and mobile layouts for consistent branding, contrast, focus/hover states, image readability, and horizontal overflow.
- Confirm animations, navigation, story movement, destination tabs, and enquiry behavior remain intact.
