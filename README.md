# Happy Hearts Journeys

# HAPPY HEARTS HOLIDAYS — PREMIUM TRAVEL AGENCY LANDING PAGE

Build a complete, modern, premium and highly attractive travel agency landing page for:

# Happy Hearts Holidays

The website must feel like a **real, premium travel brand** — cinematic, emotional, trustworthy and elegant.

The primary objective is:

**Visitor → Explore destinations → Get inspired → Submit enquiry → WhatsApp**

This is **Phase 1**.

Do NOT implement WhatsApp API automation, chatbot, CRM, database, authentication, payment gateway or automated messaging in Phase 1.

The customer should manually send the WhatsApp message after the website prepares the enquiry details.

```text

   ↓

   ↓

Validation

   ↓

   ↓

Open WhatsApp

   ↓

Customer reviews message

   ↓

Customer manually presses Send

   ↓

Happy Hearts Holidays receives enquiry

```
